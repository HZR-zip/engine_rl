# T800 Isaac Lab RL Starter

Isaac Lab extension scaffold for training a T800 velocity-tracking policy with RSL-RL PPO. The initial task is a flat-ground baseline, not a paper reproduction yet. The USD model, joint/link mapping, actuator specifications, and paper-specific MDP/training values must be supplied before a meaningful run.

## Environment

The current environment was detected as Isaac Lab 2.3.2.post1, Isaac Sim 5.1.0, Python 3.11, and RSL-RL from the installed Isaac Lab environment. Activate that environment before installing or launching this extension.

```bash
conda activate isaaclab
cd /root/EngineAI_T800
python -m pip install -e .
```

Set `T800_USD_PATH` to the converted robot USD, or place the asset at `assets/t800/t800.usd`:

```bash
export T800_USD_PATH=/absolute/path/to/t800.usd
```

The official T800 URDF and its meshes are included under `assets/t800/upstream/`. The local import copy has relative mesh paths. Convert it with Isaac Lab before running the task:

```bash
python scripts/convert_t800.py --headless
```

The converter uses a generic initial position drive only to create the USD. Before training, replace the placeholder actuator parameters in `env_cfg.py` with validated T800 control parameters. The default base link is `LINK_BASE`.

## Policy files

The official SDK walking policy is included at:

`assets/t800/upstream/assets/config/t800/rl_walking_example/policy/t800_260618_165257_30000.mnn`

This is an MNN deployment policy for EngineAI's native SDK. It cannot be loaded by `scripts/play.py`; that script expects an RSL-RL PPO checkpoint such as `model_0.pt`, generated by `scripts/train.py` under `logs/rsl_rl/t800_velocity_flat/`. The MNN file is useful as a deployment/reference artifact, but it does not provide the PPO optimizer state or Isaac Lab task configuration needed to resume training.

Before training, edit `source/t800_rl/t800_rl/tasks/locomotion/velocity/env_cfg.py` and replace:

- Initial base height and actuator effort, velocity, stiffness, and damping values with values validated against the T800 model/specification.
- Generic joint selection with the intended policy joint list and a stable order.
- Baseline observations, rewards, randomization, command ranges, and PPO settings with the paper's exact definitions when reproducing a paper.

Check the model in Isaac Sim and validate a single robot's standing pose and joint control before scaling up parallel environments. The environment currently reports no usable NVIDIA driver (`torch.cuda.is_available()` is false), so GPU simulation/training will not run until GPU access is available.

## Train and evaluate

```bash
python scripts/train.py --task T800-Velocity-Flat-v0 --headless --num_envs 16 --max_iterations 1
python scripts/play.py --task T800-Velocity-Flat-v0 --checkpoint /path/to/model.pt --num_envs 1
```

Start with a short smoke test; increase `--num_envs` and training iterations only after confirming the robot imports, contacts and actuators behave correctly. Training logs and checkpoints are written below `logs/rsl_rl/t800_velocity_flat/`.
